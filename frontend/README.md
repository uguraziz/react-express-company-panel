# Frontend

React ile geliştirilmiş şirket ve ürün yönetim paneli.

## Kullanılan Teknolojiler

- React + Vite
- Ant Design
- React Router DOM
- Axios
- Context API

## Kurulum

```bash
npm install
npm run dev
```

Uygulama `http://localhost:5173` adresinde çalışır.

> Backend'in ayakta olması gerekiyor. Önce `/backend` klasöründeki adımları tamamla.

## Özellikler

- Login / Register sayfaları
- JWT ile oturum yönetimi
- Şirket yönetimi — listeleme, ekleme, düzenleme, silme
- Ürün yönetimi — listeleme, ekleme, düzenleme, silme
- Şirket silinince bağlı ürünler de siliniyor
- Tablo filtreleme, sıralama ve sayfalama
- Dashboard — anlık istatistikler
